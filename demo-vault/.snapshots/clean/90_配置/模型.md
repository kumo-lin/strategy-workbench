# 模型

换模型只改 `active`（或者设环境变量 `MODEL_PROVIDER`），代码一行不改。

- `roles`（可选）：按角色选模型。`judgment` 管判断、拆题和对话，`execution` 管检索、抽证据和自检。没写的角色用 `active`；`MODEL_PROVIDER` 压倒一切。
- Kimi K3.1 默认开思考，一次回答前要花上千个思考 token，所以 `max_output_tokens` 要给够；它只接受 temperature = 1。

- 所有 provider 都走 OpenAI 兼容的 Chat Completions 接口。
- key 不写在这里，只写环境变量的名字；值放在 `.env.local`。
- DeepSeek 的 API 只认 `deepseek-flash` 和 `deepseek-v4-pro` 两个模型名。
- `web_tools`：联网用的 DeepSeek Search / Fetch。
