# W1-H1 员工个人AI走向端云混合的受控agent

> 假设的措辞已确认。**判断还没定**：`verdict` 为空，等 Senior 结论审批后设置。

**假设**：未来 2–3 年，企业员工用的个人 AI 会形成"端侧加云端混合、由企业管理策略约束的 agent"。

## 要成立必须满足什么
- 主流平台厂商（操作系统、办公套件、PC 厂商）都把 agent 做成端云混合，且把管控能力做进平台。
- 企业买方确实在要求对 agent 的权限和数据范围有控制。

## 什么证据会推翻它
- 员工实际用的主要是自己订阅的云端工具，企业管控长期跟不上。
- 端侧推理的成本或体验不足，混合只停在发布会。

## 打算怎么查
见 W1 报告。

## W1 调查的提议判断：需要修正（待人拍板）

供给侧成立；需求侧"取代员工自带工具"证据不足。修正后：2026 年平台和 PC 厂商已经把员工 agent 做成端云混合、带隔离和身份管控的形态；受控 agent 能否在 2–3 年内取代员工自带的云端工具，取决于 IT 管控能不能落地，交给 W2 验证。
