## Q1 联想该押哪一层，怎么拿到？

### 假设 H1：联想的资产集中在机队整合和服务这一层，明年应该押管理 / 服务层，用自研整合层加微软生态合作的方式拿到，而不是押端侧算力或 agent 本身。  [[W5-H1 联想的资产在机队与服务层]]
- 当时的假设，逐条对照：
  - ① 分析机构或财报显示联想的优势在于能整合和管理的设备类别多、商用渠道大、服务收入占比高 → 证据不足：渠道与机队大成立[^1]、服务增35%[^2]；服务收入占比高缺证据[^23]
  - ② 换机预算吃紧时，买方看重的是机队运行成本而不是 AI 硬件能力 → 成立：换机由Windows 10停更驱动，不为AI功能采购[^3]；涨价推迟渗透[^4][^22]
- 提议的判断：需要修改（① 证据不足）
- 改了什么：改成押机队与服务层，服务收入占比高还缺证据
- 回答：多半押管理／服务层、用自研整合层加微软生态合作拿到[^1][^2]；买方换机看机队运行成本，不为 AI 硬件能力付费[^3][^4]。
- 理由：
  - TruScale 同比增 35%，服务是增长引擎[^2]
  - 换机推力是 Windows 10 停更，不为 AI 功能采购[^3]
  - AI PC 涨价把 50% 渗透推迟到 2028 年[^4]
- So What：所以联想明年该把注下在机队整合与随设备交付的服务上，而不押端侧算力和 agent 本身
- 支持的证据：

## Q2 凭什么是联想，而不是微软？

### 假设 H2：微软（Windows、Intune、Agent 365、执行隔离）已经覆盖 agent 的集中配置和身份、数据边界；联想剩下的差异化只有跨设备类别的机队整合、硬件层（固件和带外）控制和随设备交付的服务。  [[W5-H2 微软之外联想还剩机队硬件与服务]]

## Q3 Qira 在企业买方这一侧有没有依据？

### 假设 H3：Qira 现在偏个人体验，企业买方一侧还没有采购需求和预算依据；它要先成为 IT 可管的 agent 才进得了企业评审，和押管理栈是先后关系，不是互斥。  [[W5-H3 Qira要先成为IT可管的agent]]
