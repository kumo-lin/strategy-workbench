## Q1 联想该押哪一层，怎么拿到？

### 假设 H1：联想的资产集中在机队整合和服务这一层，明年应该押管理 / 服务层，用自研整合层加微软生态合作的方式拿到，而不是押端侧算力或 agent 本身。  [[W5-H1 联想的资产在机队与服务层]]
- 当时的假设，逐条对照：
  - ① 分析机构或财报显示联想的优势在于能整合和管理的设备类别多、商用渠道大、服务收入占比高 → 证据不足：渠道与机队大成立[^5]、服务增35%[^6]；服务收入占比高缺证据[^14]
  - ② 换机预算吃紧时，买方看重的是机队运行成本而不是 AI 硬件能力 → 成立：换机由Windows 10停更驱动，不为AI功能采购[^1]；涨价推迟渗透[^13][^15]
- 提议的判断：需要修改（① 证据不足）
- 改了什么：改成押管理/服务层靠机队与渠道，不靠服务收入占比高
- 回答：多半押管理/服务层，用自研整合层加微软生态合作；买方为运行成本买单不为AI[^1]；服务占比还缺证据
- 理由：
  - TruScale同比增35%，服务是增长引擎[^6]
  - PC份额24.2%[^5]
  - 换机推力是Windows 10停更，不为AI功能采购[^1]
- So What：所以联想该把差异化押在机队与服务层，用自研整合加微软合作，别把溢价押在AI硬件上。

## Q2 凭什么是联想，而不是微软？

### 假设 H2：微软（Windows、Intune、Agent 365、执行隔离）已经覆盖 agent 的集中配置和身份、数据边界；联想剩下的差异化只有跨设备类别的机队整合、硬件层（固件和带外）控制和随设备交付的服务。  [[W5-H2 微软之外联想还剩机队硬件与服务]]
- 当时的假设，逐条对照：
  - ① 微软官方材料显示它在配置、身份、数据边界上已有可用的管控 → 成立：微软官方称 Intune 与 Agent 365 可设策略并治理 agent[^2][^30][^31]
