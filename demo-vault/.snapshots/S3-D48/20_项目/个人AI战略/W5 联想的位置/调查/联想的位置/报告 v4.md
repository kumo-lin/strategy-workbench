## Q1 联想该押哪一层，怎么拿到？

### 假设 H1：联想的资产集中在机队整合和服务这一层，明年应该押管理 / 服务层，用自研整合层加微软生态合作的方式拿到，而不是押端侧算力或 agent 本身。  [[W5-H1 联想的资产在机队与服务层]]
- 当时的假设，逐条对照：
  - ① 分析机构或财报显示联想的优势在于能整合和管理的设备类别多、商用渠道大、服务收入占比高 → 证据不足：商用渠道和PC规模有据[^7]；服务收入占比高被[^13] 反向指向，要再拆[^6][^14]
  - ② 换机预算吃紧时，买方看重的是机队运行成本而不是 AI 硬件能力 → 证据不足：买方不为AI硬件能力付费成立[^8]；看重机队运行成本只有专家意见[^15]
- 提议的判断：证据不足
- 改了什么：还判断不了，缺服务收入占比与买方看重机队运行成本的证据
- 回答：多半押管理／服务层，靠自研整合层加微软生态合作拿[^1]；还缺服务收入占比和买方看重运行成本的证据
- 理由：
  - TruScale 同比增 35%，服务是增长引擎[^6]
  - PC 份额 24.2%，领先地位进一步加强[^7]
  - 换机推力是 Windows 10 停更，企业不为 AI 功能采购[^8]
- So What：所以联想可以先把管理／服务层列为候选，但还缺服务收入占比和买方看重运行成本的证据

## Q2 凭什么是联想，而不是微软？

### 假设 H2：微软（Windows、Intune、Agent 365、执行隔离）已经覆盖 agent 的集中配置和身份、数据边界；联想剩下的差异化只有跨设备类别的机队整合、硬件层（固件和带外）控制和随设备交付的服务。  [[W5-H2 微软之外联想还剩机队硬件与服务]]
- 当时的假设，逐条对照：
  - ① 微软官方材料显示它在配置、身份、数据边界上已有可用的管控 → 成立[^2][^29]
  - ② 能看到微软管不到的部分（非 Windows 设备、没走配置路径的 agent、硬件层） → 证据不足：（系统复核：成立要至少 2 个独立来源、其中 1 个 A/B 级，这条只有 1 个独立来源，最高 C 级，改为证据不足）官方承认工具可绕过既有管控[^30]；断电时可见性中断[^31]
  - ③ 其他 PC 厂商在这几块没有明显领先联想 → 证据不足：带外能力各厂商通用[^10]；联想门户落后仅 C 级证据[^3]
- 提议的判断：需要修改（② 证据不足、③ 证据不足）
- 改了什么：改成：微软覆盖成立；硬件层归 Intel、各厂商通用，联想只剩机队整合与服务
- 回答：微软已管住配置与身份[^2]；联想多半只剩机队整合与服务，还缺对手对比的 A 级证据[^3]
- 理由：
  - 微软称 Intune 与 Agent 365 可设策略、监控风险并治理 agent[^2]
  - 系统无法启动或设备断电时，Intune 的可见性中断[^31]
  - 评测时联想没有合作门户，戴尔、HP 已接入 Intune[^3]
- So What：所以联想别把固件和带外当独有卖点，差异化要放在机队整合与随设备交付的服务上[^10]

## Q3 Qira 在企业买方这一侧有没有依据？

### 假设 H3：Qira 现在偏个人体验，企业买方一侧还没有采购需求和预算依据；它要先成为 IT 可管的 agent 才进得了企业评审，和押管理栈是先后关系，不是互斥。  [[W5-H3 Qira要先成为IT可管的agent]]

  - ② 找不到企业规模部署或采购 Qira 的案例 → 证据不足：只有个人版按用户月费售卖[^4]；企业部署或采购案例还缺，企业版定价[^65] 不算案例[^22]
  - ③ 受监管行业对员工端 agent 的要求，Qira 目前满足不了，要靠管理层补 → 证据不足：受监管行业的管理要求构成准入[^5]；Qira 满足不了这一半还缺证据[^11][^66]

- 改了什么：还判断不了，缺企业部署案例和 Qira 满足监管的证据
- 回答：企业侧采购案例还没有[^4]；受监管行业的管理要求构成准入[^5]，Qira 满足得了还没有证据

  - 金融监管总局要求设定 AI 功能边界、数据权限，责任可追溯[^5]

  - 承诺 2026 年第四季度到 2027 年第二季度取得三项认证[^62]
- So What：所以联想该先把 Qira 做成 IT 可管的 agent，再去要企业采购
