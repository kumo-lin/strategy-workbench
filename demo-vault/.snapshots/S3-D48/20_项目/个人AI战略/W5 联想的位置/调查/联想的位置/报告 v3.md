## Q1 联想该押哪一层，怎么拿到？

### 假设 H1：联想的资产集中在机队整合和服务这一层，明年应该押管理 / 服务层，用自研整合层加微软生态合作的方式拿到，而不是押端侧算力或 agent 本身。  [[W5-H1 联想的资产在机队与服务层]]
- 当时的假设，逐条对照：
  - ① 分析机构或财报显示联想的优势在于能整合和管理的设备类别多、商用渠道大、服务收入占比高 → 证据不足：机队覆盖与商用渠道有[^1]，服务收入占比小[^12][^13]，这一条要再拆[^6]
  - ② 换机预算吃紧时，买方看重的是机队运行成本而不是 AI 硬件能力 → 成立：换机推力是 Windows 10 停更、不是 AI 功能[^7]，涨价又推迟普及[^14][^15]
- 提议的判断：需要修改（① 证据不足）
- 改了什么：改成押机队覆盖与商用渠道，服务随设备交付、不靠可管理溢价
- 回答：押管理/服务层，靠机队覆盖与商用渠道拿到，自研整合层加微软生态合作[^1]
- 理由：
  - TruScale 收入同比增 35%，服务层是增长引擎[^6]
  - PC 份额 24.2%，领先第二名超过五个百分点[^1]
  - 企业换机推力是 Windows 10 停更，不是 AI 能力[^7]
- So What：所以联想应先押机队整合与随设备交付的服务，把可管理做成准入要求，不靠它加价[^1]

## Q2 凭什么是联想，而不是微软？

### 假设 H2：微软（Windows、Intune、Agent 365、执行隔离）已经覆盖 agent 的集中配置和身份、数据边界；联想剩下的差异化只有跨设备类别的机队整合、硬件层（固件和带外）控制和随设备交付的服务。  [[W5-H2 微软之外联想还剩机队硬件与服务]]
- 当时的假设，逐条对照：
  - ① 微软官方材料显示它在配置、身份、数据边界上已有可用的管控 → 成立：配置与身份有官方材料[^2]；数据边界只从「可绕过」侧面提到[^30][^31][^9]
  - ② 能看到微软管不到的部分（非 Windows 设备、没走配置路径的 agent、硬件层） → 证据不足：硬件层缺口只有C级证据[^32]；跨设备类别已被Intune覆盖[^33][^34][^35]
  - ③ 其他 PC 厂商在这几块没有明显领先联想 → 证据不足：HP、戴尔已有Intune门户，联想没有[^5]；缺A/B级对比[^36][^37][^38][^39]
- 提议的判断：需要修改（② 证据不足、③ 证据不足）
- 改了什么：改成：只剩随设备交付的服务，硬件层不独有
- 回答：凭随设备交付的机队服务，不是管理能力：微软已管配置[^2]，硬件层归Intel[^4]，联想没有门户[^5]
- 理由：
  - 微软称Intune与Agent 365可设策略、治理全组织agent[^2]
  - 带外与AI运维由Intel vPro提供，各OEM通用[^4]
  - 测试时联想没有Intune合作门户，HP与戴尔有[^5]
- So What：所以联想押管理/服务层时，不能把硬件层当独占卖点，要押随设备交付的服务。

## Q3 Qira 在企业买方这一侧有没有依据？

### 假设 H3：Qira 现在偏个人体验，企业买方一侧还没有采购需求和预算依据；它要先成为 IT 可管的 agent 才进得了企业评审，和押管理栈是先后关系，不是互斥。  [[W5-H3 Qira要先成为IT可管的agent]]
- 当时的假设，逐条对照：
  - ① 联想官方材料里看不到面向企业 IT 的 Qira 管理能力，或能力还在规划中 → 证据不足：只有 C 级来源说合规认证还在规划中，同源又称已有管理能力[^64][^65][^66]
  - ② 找不到企业规模部署或采购 Qira 的案例 → 证据不足：没有部署或采购案例；企业版定价只有 C 级单一来源[^3][^67][^23]

## 对 workplan 的影响
- H1 要改：把「服务收入占比高」这一条从必须成立的条件里去掉，改成靠机队与商用渠道、服务随设备交付，不靠可管理溢价[^12][^13]
- H2 要改：把「跨设备类别的机队整合」和「硬件层控制」从联想剩余差异化里删掉，只留随设备交付的服务[^33][^36][^5]
- H3 保持证据不足：先补查联想官方文档、管理员手册里Qira面向企业IT的管理能力，以及企业规模部署或采购案例，再判断它和押管理栈的关系
- 追加调查：联想服务收入中管理服务（DaaS、托管服务）与项目制收入各占多少；买方换机时看重哪些因素的直接排序
- 追加调查：带外与固件管理在实际采购里是差异化还是标配；HP、戴尔、联想在同一测试条件下的独立对比（现有评测日期不详）
- 要和 WS-A 对齐：买方采购逻辑里换机预算吃紧时机队运行成本与AI硬件能力的权重，Q1 的成立条件②依赖这一条
- 要和 WS-B 对齐：员工侧 agent 的IT管理要求，Q3 的条件①③要靠它补
- 要问专家：企业换机预算吃紧时，机队运行成本与AI硬件能力在决策中各占多大权重
