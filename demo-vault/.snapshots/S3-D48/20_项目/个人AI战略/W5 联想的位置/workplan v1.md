# workplan v1｜W5 联想的位置

> 状态：**已通过 G1**。本文件是开工前的判断，不是调查结果。这是 W2 期间提前做的快速研判，W5 正式阶段再深挖。

## 要回答的问题与要支撑的决策

**核心问题**：联想明年在商用 AI PC / 个人 AI 上，站在哪一层、凭什么、Qira 放在哪？

**它要支撑的决策**：联想明年在商用 AI PC / 个人 AI 上，差异化**押哪一层**（管理 / 安全栈、端侧算力、agent 本身）× **怎么拿到**（自研 / 合作 / 收购）（[[20_项目/个人AI战略/项目|项目]]）。W5 回答其中"联想站在哪里"这一半，比较和下注留给 W6–W7。

**为什么现在做**：“Senior 判断，高层最关心的是联想在各层的位置，所以在 W2 期间先做一版快速研判，W5 正式阶段再深挖。”[[20_项目/个人AI战略/项目#^w5]]

**范围**：只看有统一机队管理的大中型企业、跑在 AI PC 上的个人 AI；以公开资料为主，不做联想内部数据分析（[[20_项目/个人AI战略/项目|项目]]）。

## 前提

- 高层的方向：“重点看 IT 能不能管。”[[20_项目/个人AI战略/会议/2026-10-16 高层周会（模拟）#^m1]]
- 决策的两维（押哪一层 × 自研 / 合作 / 收购）按[[20_项目/个人AI战略/项目|项目]]里写的，不重新讨论。

## Day-1 answer

**（假设，不是结论）** 联想的资产集中在机队整合和服务这一层，应该押管理 / 服务层，用"自研整合层 + 微软生态合作"拿到；微软已经管住了 agent 的配置和身份，联想剩下的是跨设备类别的机队、硬件层控制和随设备交付的服务；Qira 只有先成为 IT 可管的 agent，才进得了企业评审。

## 问题树与假设

按决策要回答的三件事拆，三问一次查完。

### Q1 联想该押哪一层，怎么拿到？
**假设 H1**：联想的资产集中在机队整合和服务这一层，明年应该押管理 / 服务层，用自研整合层加微软生态合作的方式拿到，而不是押端侧算力或 agent 本身。[[W5-H1 联想的资产在机队与服务层]]

### Q2 凭什么是联想，而不是微软？
> "凭什么是我们"这一问。最强的对手是微软（Intune / Agent 365），不拿行业平均比；HP、戴尔、Intel 也在这一问里对照。

**假设 H2**：微软（Windows、Intune、Agent 365、执行隔离）已经覆盖 agent 的集中配置和身份、数据边界；联想剩下的差异化只有跨设备类别的机队整合、硬件层（固件和带外）控制和随设备交付的服务。[[W5-H2 微软之外联想还剩机队硬件与服务]]

### Q3 Qira 在企业买方这一侧有没有依据？
**假设 H3**：Qira 现在偏个人体验，企业买方一侧还没有采购需求和预算依据；它要先成为 IT 可管的 agent 才进得了企业评审，和押管理栈是先后关系，不是互斥。[[W5-H3 Qira要先成为IT可管的agent]]

## MECE 和充分必要的自检

- **怎么拆的**：按决策要回答的三件事拆：联想该押哪一层、怎么拿到（Q1）；这一层里凭什么是联想、不是最强的对手微软（Q2）；联想自己已经有的 agent（Qira）在企业这一侧有没有依据，和押管理栈是什么关系（Q3）。
- **不重叠**：Q1 只看联想自己的资产和买方看重什么；Q2 只看对手（微软，以及 HP、戴尔、Intel）已经做到了哪一步；Q3 只看 Qira 这一个产品在企业这一侧的依据。联想的机队和服务资产只在 Q1 里用，Q2 引用 Q1 的结论，不重新论证。
- **不遗漏**："押哪一层 × 怎么拿到"的决策要知道三件事：联想有什么（Q1）、对手已经有什么（Q2）、联想已经押下去的 agent 怎么处理（Q3）。端侧算力和 agent 本身作为"不押"的选项，在 Q1 的假设和反证里看。员工侧在 WS-B，买方的采购逻辑在 WS-A。
- **充分**：三问都答了，就能说清联想站在哪一层、凭什么、Qira 放在哪，够 W6–W7 比较选项用。
- **必要**：少了 Q1，不知道该押哪一层；少了 Q2，只知道这一层值得做，不知道该不该由联想来做；少了 Q3，押管理栈和已经发布的 Qira 是互补还是冲突，说不清。

## 每个假设怎么验证

### H1（Q1，押哪一层）
- **必须成立的条件**：① 分析机构或财报显示，联想的优势在于能整合和管理的设备类别多、商用渠道大、服务收入占比高；② 换机预算吃紧时，买方看重的是机队运行成本，而不是 AI 硬件能力。
- **要什么证据**：能证明的：联想财报里的机队覆盖和服务收入、分析机构对联想机队优势的评价、买方调研里换机时看重什么。能推翻的：联想的服务收入增长主要靠项目或其他业务；买方为端侧算力或 agent 能力单独付钱。
- **去哪里查**：联想财报、分析机构，以及知识库里的买方调研。
- **用什么方法**：desk research，先查知识库。
- **怎么找反证**：联想服务收入的增长不靠管理服务；买方为端侧算力或 agent 能力单独付钱；分析机构认为联想的机队优势被高估。
- **做到什么程度停**：至少 2 条互相独立的支持证据、其中至少 1 条 A/B 级，且没有没被驳倒的同等级反证，就下判断；不够就标"证据不足"，转成要问专家的问题。

### H2（Q2，凭什么是联想）
- **必须成立的条件**：① 微软官方材料显示它在配置、身份、数据边界上已经有可用的管控；② 能看到微软管不到的部分（非 Windows 设备、没走配置路径的 agent、硬件层）；③ 其他 PC 厂商在这几块没有明显领先联想。
- **要什么证据**：能证明的：微软官方文档，逐层对照可管理性三层；HP、戴尔、Intel 在设备管理层做到了哪一步。能推翻的：微软已经覆盖跨设备类别管理、硬件层控制或随设备交付的服务；HP、戴尔在管理层已明显领先。
- **去哪里查**：微软、HP、戴尔、Intel 的官方材料，独立评测。
- **用什么方法**：desk research；厂商自述照用，但一律标出立场，找独立评测印证。
- **怎么找反证**：同"能推翻的"。
- **做到什么程度停**：同 H1。

### H3（Q3，Qira）
- **必须成立的条件**：① 联想官方材料里看不到面向企业 IT 的 Qira 管理能力，或能力还在规划中；② 找不到企业规模部署或采购 Qira 的案例；③ 受监管行业对员工端 agent 的要求，Qira 目前满足不了，要靠管理层补。
- **要什么证据**：只用联想官方文档、管理员手册和企业案例原文；监管要求只用监管原文。能推翻的：联想已提供 Qira 的企业管理能力并有企业规模采购；企业为 Qira 单独列了预算。
- **去哪里查**：联想官方文档和发布材料；监管机构官网。
- **用什么方法**：desk research，只用原文；找不到就写证据不足。
- **怎么找反证**：同"能推翻的"；另外看监管对员工端 agent 是不是并无额外限制。
- **做到什么程度停**：同 H1。

### Day-1 answer 本身的反证
如果这句答案是错的，痕迹会出现在：联想的服务收入不靠管理服务（推翻"资产在机队与服务层"）；微软或 HP、戴尔已经覆盖了联想声称的差异化（推翻"凭什么是联想"）；Qira 已有企业规模采购（推翻"Qira 要先成为 IT 可管的 agent"）。

## 金字塔骨架

**Key message**：联想能赢的地方在机队和服务，不在算力和 agent；Qira 要先变成 IT 可管的 agent，才是企业里的资产。

**结构**：核心问题的回答由 Q1–Q3 的回答组装而成。
1. Q1 → 押哪一层、怎么拿到（H1）→ 对联想明年意味着什么。
2. Q2 → 凭什么是联想（H2）→ 能守住的差异化还剩哪些。
3. Q3 → Qira 放在哪（H3）→ 它和押管理栈的先后。
4. 每个回答下面挂证据，标信源等级和立场。
