# 节奏（市场部）

市场部按 campaign 走，4 周一个周期：brief → 创意方向 → 制作 → 投放复盘。每周一次排期会，周三中期 check，周五复盘。

一个 campaign 周期的节奏如下：

| 时间 | 谁 | 做什么 |
|---|---|---|
| 第 1 周 | CMO + Planner | brief 共创：定目标、受众、预算、成功标准 |
| 第 2 周 | Planner | 出创意方向，交创意方向审批（CMO） |
| 第 3 周 | Planner + 制作 | 制作物料，投放前审批（法务 + 品牌） |
| 每周三 | Senior Planner | 中期 check：进度、风险、要不要调方向 |
| 每周五 | 全组 | 复盘：本周产出、下周排期 |
| 第 4 周末 | 全组 | 投放复盘，出复盘报告 |

两道关卡：

- **创意方向审批（CMO）**：创意方向定稿前由 CMO 批。
- **投放前审批（法务 + 品牌）**：物料投放前必须过法务和品牌两道。

对照战略部那张表看：周一定题换成第 1 周 brief 共创；周一到周四的调查换成第 2–3 周的创意与制作；周四汇总换成周五复盘；周五高层周会换成每周排期会加周三中期 check。关卡从 G1 workplan + 结论审批，换成创意方向审批 + 投放前审批。
